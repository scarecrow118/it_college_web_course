Архітектура системи класів

Модульна система управління онлайн-курсами на базі стандартів ES6 Modules:

Person

Базовий суперклас для сутностей користувачів. Конструктор із name та метод getInfo().

Teacher extends Person

Сутність викладача: список закріплених курсів, методи addCourse() та розширений getInfo().

Student extends Person

Сутність студента: список обраних курсів, метод перегляду записів viewCourses().

Course

Курс: назва, список зарахованих студентів, методи addStudent() та getStudents().
