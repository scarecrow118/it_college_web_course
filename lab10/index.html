Створення серверного застосунку на Node.js

Студент: Чупіль Юрій | Група: КН-310 (userId: 23)

Опис серверної архітектури

HTTP REST API сервер реалізовано на вбудованому модулі node:http без використання сторонніх залежностей. Конфігурація проєкту налаштована на стандарт ES-модулів ("type": "module").

  • CORS політика: налаштовано заголовки Access-Control-Allow-Origin: * для взаємодії з Angular та клієнтськими застосунками.
  • Preflight OPTIONS: запити перевірки CORS успішно завершуються зі статусом HTTP 204 No Content.
  • Експорт моделі: файл data.js містить масив об'єктів Todo з прив'язкою до ідентифікатора студента (userId: 23).
